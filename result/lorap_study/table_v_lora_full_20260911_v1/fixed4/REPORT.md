# 标准权重 LoRA：联合 QAT 对照

训练完成 10/10 组；最终测试完成 10 组；已完成。

## 协议

三组均联合训练骨干与既有可训练量化参数。no_prompt 和 lora 移除所有提示；main 沿用固定提示方法，MNIST 保留输入 GPF。LoRA 是标准权重分支的联合 QAT 对照，不是冻结骨干的 PEFT，也不是 GLoRA/GraphLoRA 论文复现。

LoRA 使用量化线性层已有的量化输入：Linear(x_q,W_q,b)+(alpha/r)x_q AᵀBᵀ；A 为 Kaiming 初始化，B 为零，dropout=0，因子为 FP32。分支不会合并后重新量化，特征预算只累计一次。公共骨干初始化、训练随机种子和图数据顺序配对。

各组按最低验证交叉熵选模，平局取较早轮次；每个数据集全部预定训练完成后才释放测试。main 的条件统计只由训练节点/图校准。历史图任务的 none 仍保留输入 GPF，与本轮完全无提示的 no_prompt 不同，因此本轮从头训练同期对照。

本组为固定 INT4 QAT：所有位宽参数冻结为 4 个有效位，量化尺度和骨干联合训练，损失仅为分类 CE。非负特征内部使用带额外符号位的量化代理，统计有效位宽时减去该位。

## 解释与复现

相同 rank 不代表等容量；输入维度较大的节点模型尤其如此。FP32 适配因子的参数字节数单列，校准缓冲区字节数见 CSV；量化预算代理与逻辑位宽不代表实际整数部署或物理模型大小。训练秒包含训练和逐轮验证，不含离线校准及磁盘检查点写入；峰值为每组训练的 CUDA allocated memory。

图任务使用官方完整划分。种子数以配置为准；均值与标准差本身不构成显著性检验。原数据划分被重复使用，不是新的独立测试集。CUDA scatter 归约可能产生微小数值差异；验证复现容差沿用既有 5e-4 CE。
