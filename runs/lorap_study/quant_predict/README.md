# 仅量化信息的误差监督低秩提示：首轮验证

用户部署条件不允许提示读取量化前消息。此前 `residual_transfer` 的 R=X−Q(X) 侧通道实验需要发送端原值，保留为有该信息时的机制诊断，不能用来证明本轮部署条件下可用。
本轮采用量化条件 LoRAP 形式的预测器；训练时可计算误差目标，推理时只能根据量化消息及已有元数据预测修正。
这不是原论文 LoRAP 的完整训练复现，也不是上一轮真实残差通道的部署版本。

## 固定协议

- Cora、CiteSeer、PubMed × GIN、GCN、GAT × seeds 41、42、43，共 27 组；完整公共图、官方 public 划分。
- 复用 `residual_transfer_20260914_v2` 全部 27 个无补偿最佳骨干。固定骨干参数、量化参数、BN 状态，eval 模式关闭 dropout。基线训练历史、位宽合法性修复等沿用来源报告。
- 每组训练 task、error、mlp 三个变体各 100 轮，共 81 次适配。epoch 0 纳入最低验证 CE 选模，平局选较早轮次，保存最佳与最后一轮。
- 所有适配完成并锁定哈希后，导出模型分别评估一次测试集，共 81 个新测试条件；无补偿基线测试结果引用已有文件，不重新挑选。
- 公共测试集历史已使用。本轮是探索性验证，不能声称从未查看过的独立确认集。不根据测试分数选择超参/版本或省略负结果。
- 全部模型前向、反向、校准、诊断和等价测试使用 GPU。CPU 仅用于文件操作、统计和绘图。

## 预测器与三个对照

对每个量化聚合块，S_q=T(Q(X))，输出 S_q+p。GIN 仅第二层，T 包含邻居和与 (1+epsilon) 自项；GCN/GAT 各两层，T 为当前归一化/注意力加权聚合。
GAT 的目标固定同一次前向的量化值所产生的注意力，只衡量值消息量化误差，不含注意力本身的量化误差。

输入 h 是按训练节点统计标准化的 S_q，条件 c 是按同一训练节点统计标准化并裁剪至 [-5,5] 的四项：
1. 实际消息边的入度 log1p；
2. 入边源节点的平均对数步长；
3. 入边源节点的平均舍入 signed 位宽 / 8；
4. 入边源节点量化码位于非退化码本端点的比例。

无入边时后三项为零。端点占比不能区分恰好落在端点与超范围裁剪，不称为真实饱和率。条件停止梯度。
对按通道量化器，元数据跨节点共享；对 GAT 按节点量化器，统计使用真实源节点参数。步长和位宽属于解码已有元数据，不读取源节点原值。

低秩提示 p = s_out * 2sigmoid(g(c)) * softmax(a(h)+C c) * A B。
num_prompts=20、每个量化块 rank=2；GAT 第一层在拼接后的 64 维上使用总 rank 2，不是每头 rank 2。
每层独立提示。B 初始化为零，A Xavier 初始化，条件投影 C 和门控 g 均零初始化；task/error 每一个初始参数完全相同。
s_out 为该层训练节点量化聚合值 RMS。标准化的每通道标准差下限为 0.1*该 RMS+1e-6，避免常量通道导致极大增益。所有推理统计都只从量化数据获得并固定。

- task：上述低秩提示，仅训练分类 CE。
- error：与 task 相同结构、参数量和初始化，训练 CE + 0.1 * 平均逐层归一化局部误差 MSE。
- mlp：接收同样 h,c 的两层 ReLU 残差 MLP，仅训练分类 CE。选择最接近低秩提示参数量的整数隐藏宽度，每层差异 <=5%，末层权重和 bias 零初始化，无填充参数。

Adam，零权重衰减；学习率 GAT-CiteSeer/PubMed=0.005，其余=0.01。冻结量化预算与骨干，因此不添加常数存储惩罚；提示/标准化 FP32 状态开销另行报告。

## 训练用参考与部署边界

局部目标 e=stop_gradient(T(X)-T(Q(X)))。在每次 error 训练前向中固定当前层输入、权重、量化参数和当前注意力，使用训练目标节点计算 ||p-e||²。
每层 MSE 除以无提示基线训练节点的误差 MSE（下限 1e-12），各层取平均；归一化尺度属于训练元数据，不写入预测器或部署导出文件。
损失不直接拉动参考路径或骨干参数，但提示输出及后续量化主路径按现有 STE 反传。
本轮没有额外的纯误差预训练阶段或超参搜索。

`QuantOnlyModel.apply_quantized(i, q, operator, scale, bits)` 不接收 X、标签或误差目标。普通 forward 使用 `PredictionCallback`，明确忽略历史接口传入的量化前参数；只有独立 `TeacherCallback` 在监督训练/诊断中调用 local_target。
task/mlp 的训练与全部验证选模、测试都使用普通 forward，无额外参考聚合。训练校准的误差尺度虽统一计算，但 task/mlp 不使用它；测试证明修改这些目标不影响推理标准化。

`inference.pt` 自包含冻结骨干、提示参数、量化统计和维度信息。导出重新加载后，在参考函数被替换为抛错函数、量化前回调参数替换为 NaN、移除输入标签时，输出应逐元素完全相同。
它仍是项目的 GPU 假量化/浮点计算实现，不能据此宣称端到端整数推理、加速或零浮点开销。提示的输入是量化码反量化后的数值，其信息可由量化码和步长获得；无需额外残差信息传输。
现有按节点量化器绑定公共图节点数/索引，导出沿用该限制，不宣称可直接迁移到未知节点图。

## 误差指标与判断标准

验证节点记录当前适配模型输入下的局部误差，以及所有变体在同一无提示骨干输入下的固定输入对照。后者避免把不同模型上游特征变化当作误差预测能力提升。
记录补偿前后平方误差、1-after/before、提示与目标的余弦、前后误差谱、累计能量，以及同一提示在验证节点内随机置换 20 次的平均误差作为方向/节点对应关系对照。
节点数超过 4096 时固定种子抽样；实际三个验证 mask 均 500 个节点。零参考误差时下降比例记 null。
诊断开启与关闭输出必须精确一致。上述指标不是完整 FP32 模型误差，也不自动代表分类提升。

若 error 比 task 更准确预测验证局部误差，才支持“误差监督改善了补偿”；若测试准确率也提高，才进一步支持任务收益。参数匹配 MLP 控制容量，task/error 精确等容量控制监督差异，但不充分证明架构机制具有量化独占性。
如所有条件均无收益或选 epoch 0，也完整报告，不以准确率必须提升作为完成条件。
