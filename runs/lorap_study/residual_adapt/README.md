# 真实残差通道的任务适配

本轮修复阶段保留先前全部 LoRAP 方法与冻结残差通道实验。新增代码独立放在 residual_adapt。

## 锁定范围

- MNIST、CIFAR10，原无聚合提示最佳检查点，种子 41、42、43。
- 完整官方训练集及验证集，每组 20 轮、batch 128，共 24 次训练。
- 四个变体：gate_only（只训练 4 个门控）、none_ft（无通道继续训练）、
  gate_ft（门控＋骨干微调）、higher16_ft（同额外消息预算加位宽＋骨干微调）。
- 所有模型前向、反向和 BN 校准均在 GPU；不开新测试集评估。
- 不新增误差辅助损失，不改变 rank、选基方法、量化器参数或训练预算目标。

## 门控与梯度

每层 U = TQ(X) + alpha * delta，alpha 是独立可训练标量，初始值 0。
每次 Adam 更新后投影到 [0,1]。没有 sigmoid 的非零初值或 ReLU 在零点的梯度阻断。
alpha=0 的初始前向与原检查点一致；alpha=1 与上一阶段真实残差通道一致。
门控率 0.01，骨干率为原主学习率的 0.1 倍（两数据集均 0.0001），20 轮固定学习率、零权重衰减。

真实残差 X-Q(X)、INT8 编码及 INT32 邻居传输每次前向重算，整个侧分支停止梯度；
仅门控和主干路径参与反向。这样明确避免直接穿过整数转换，或让两个 STE 导数相减
导致未知的残差梯度语义。此梯度约定是设计选择，不声称是硬量化的精确导数。

骨干微调包含输入 GPF+、骨干权重、epsilon 和 BN 仿射参数；量化器步长、位宽全部冻结。
冻结量化器参数后，原存储惩罚对可训练的骨干及门控没有梯度，因此只优化分类损失。
注意原 uniform 分配实际按特征幅值选择量化槽位，实际位宽和存储代理值仍可变化，并非数值常数。
收尾另在 GPU 记录各所选条件实际使用的有效位宽、逻辑激活流量和存储代理值。
基和 INT8 尺度复用前一阶段训练集校准结果。
训练期间骨干微调组正常更新 BN 运行统计；只训练门控组保持整个骨干 eval 状态。
量化器元数据和残差基逐轮核对；只训练门控组逐轮核对骨干全部状态。

## 配对、选模与 BN 对照

同一种子、同一轮使用完全一致的数据顺序，逐轮保存顺序哈希。启用确定性 GPU 运算。
最低验证 CE 选模，包含 epoch 0，平局保留较早轮次；训练 20 轮后保存最后轮指标及最佳模型。
若最佳模型为 epoch 0 或门控全部为零，只报告恢复基线，不称为机制收益。
原验证集已多次用于研究探索，结果不能当作新的独立测试结论。

只训练门控完成后，使用同一组 1024 张训练图做三种 BN 干预：
gate_only_bn（已选门控模型）、none_bn（原模型、门控为零）、unit_gate_bn（原模型、门控为一）。
每种干预从对应原始状态重新开始，不累计统计改动。
按网络顺序逐个 BN 收集前向输入的节点加权均值、无偏方差，更新统计后再校准下一个 BN。
全过程 eval，不用 batch 归一化临时输出代替部署时前缀。只改运行均值、方差与计数器；
不更新权重、不用标签、不按验证指标选择 BN 方案。每个干预报告前后变化，保留负结果。

## 预算与交付

残差通道仍每节点每层增加 16 消息位，四层固定基及尺度 3552 字节；新增门控共 16 字节，合计 3568 字节。
不因为门控接近零而声称获得消息节省，本参考实现仍计算侧通道；若后续部署静态移除零门控层，必须另计。
加位宽对照沿用原训练校准的通道表，量化动态范围固定；参考实现还缓存四层各 16 个 INT64 通道索引，共 512 字节。
同消息预算不等于同总模型存储。
