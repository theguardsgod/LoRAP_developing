# 真实量化残差通道：第一阶段

保留原 LoRAP、条件提示、均匀 rank 及误差谱初始化方法与全部历史结果。
本目录独立实现新机制；不修改历史量化器和训练脚本。

## 机制

对当前层量化器输入 X 定义 R = X − Q4(X)。X 已包含上游计算与量化，
不是完整 FP32 教师特征。共享正交基 B∈R^(110×2) 编码 R B，使用训练校准的
逐通道对称 INT8 尺度（绝对最大值 /127，最小 1e-12）。消息边只增加两个
INT8 值；邻居码以 INT32 累加，再与实数 (1+epsilon) 加权的自身码合并、
反量化并乘 Bᵀ。解码和编码共享同一份 B，不传输全维浮点残差。

T = A + (1+epsilon) I，使用真实有向消息边，去掉显式自环，保留重复边。
输出为 U = T Q4(X) + T Z Bᵀ，Z 是残差码的反量化值。
图基是 (TR)ᵀ(TR) 的前两个特征向量；普通残差 PCA 用 RᵀR。
都是未中心化二阶矩，不减均值，没有新增可训练参数。

令 eta = Z − RB，则在正交基与固定线性 T 下：

    ||TX−U||² = ||TR(I−BBᵀ)||² + ||T eta||²

数值实现检查相对恒等式误差；误差确实下降当且仅当
||T eta||² < ||TRB||²。关闭当前量化时残差通道严格为零。
这个结构属性本身不是性能归因证据。

## 固定实验范围

- MNIST、CIFAR10，种子 41–50，各使用已训练的无聚合提示最佳检查点。
- 完全冻结骨干、量化器、输入 GPF+ 和 BatchNorm 状态；不创建优化器。
- 官方训练划分固定分层抽样 512 图，256 拟合基和尺度，256 留作校准外检查。
  标签只用于预先固定的分层抽样与评价，不进入编码、选基、尺度或通道收益计算。
- 每层统一的随机节点优先级，最多 4096 节点拟合谱基；尺度使用全部 256 拟合图。
- 普通随机正交基、残差 PCA、图基、额外 8/16/32/64/110 个主消息位的对照。
  根据拟合节点上逐通道传播误差改善排序，只提高正收益通道，不凑数。
- 全部控制使用官方完整验证划分；不读取测试数据、不再测试。
- 验证集固定输入局部诊断同时计算所有控制；另记录各方法全部四层启用后的
  逐层诊断。浮点残差码、图内打乱、关闭通道、消息量化旁路用于机制干预。
- 浮点残差是诊断参考，按两个 FP32 值计 64 额外位，不能当作低开销结果。

## 预算与计时

基础消息每节点每层 110×4=440 位。INT8 rank 2 增加 16 位（3.64%）。
正交基每层 880 字节，尺度 8 字节，共四层 3552 字节，均计入静态存储，
即使它们不是训练参数。提高主消息精度对照复用已有逐通道位宽与尺度元数据槽位。
Python 校准文件、索引、运行时对象和参考实现峰值显存单独报告。

计时使用 batch 32/128，预热 3 次、GPU 同步测量 10 次，关闭诊断。
提高位宽使用已有量化器一次调用，基于拟合通道表构造位宽和尺度；研究实现
构造元数据的开销包含在计时内。这里没有原生 INT4 GEMM 或融合算子，
不能用 fake-quant 参考执行时间宣称整数部署速度。INT8 编码与 INT32 累加是真实类型。

## 创新边界

低秩残差与混合精度本身已有先例，例如 [ResQ](https://arxiv.org/abs/2412.14363)。
本轮验证的候选区别是“动态图消息的真实量化残差 + 按图传播误差校准的压缩基”。
必须分别检验局部补偿、图基优于普通 PCA、同预算效率和分类收益；不能相互替代。
