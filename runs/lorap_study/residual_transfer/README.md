# 只训练门控：跨数据集与模型验证

固定矩阵为 Cora、CiteSeer、PubMed × GIN、GCN、GAT × 种子 41、42、43，共 27 组。
沿用 Planetoid 官方公共划分、原始特征，完整图传播；只用训练 mask 计算训练损失。
训练、校准、诊断和测试前向全部使用 GPU。原有源码、结果和检查点保留。

正式报告使用 v2。v1 已完成并查看过结果，后续位宽核对发现部分 GCN 的 signed bit 参数舍入为 0，但原函数 qmax=-0.5 仍产生非零输出；无法解释为有效零位编码。
v2 对全部新训练基线的可训练 signed bit 参数在每次更新后统一投影到 [1,16]，避免负 qmax，完整重跑同一矩阵。b=1 时 qmax=0，输出恒零；正值特征的 unsigned 等效位宽为 b-1。
复用的六个 GIN 检查点逐项确认 rounded signed bit>=1，保持不变。v1 源码、检查点、全部正负结果保存；此次修订由编码合法性驱动，不按准确率挑选版本或条件。
两版各条件分别评估过一次测试指标，不能声称整个研究从未重复查看公共测试集。

## 模型与训练

- GIN：两层、16 维，复用当前项目布局，仅第二层有消息量化和门控。Cora、CiteSeer 共 6 组使用已有无聚合提示最佳检查点；PubMed 新训练。
- GCN：两层、16 维，每层线性变换后量化消息，按含自环的对称度归一化权重聚合。沿用项目在线性变换内应用 bias 的位置。
- GAT：两层，第一层 8 头、每头 8 维，第二层 1 头、输出类别维；沿用项目的注意力参数量化、注意力 logits 量化及每节点值量化器。保留 ReLU 和 README dropout 配置。
- GAT 新基线输出原始 logits，训练和验证使用交叉熵；修正历史脚本先 softmax 再交叉熵及用概率做 NLL 的不一致。省去历史未使用的独立 weight 参数，因此不声称是该脚本的逐位训练复现。

共新训练 21 个基线，各 200 轮；复用 6 个基线。使用 README 对应量化学习率和存储惩罚，具体配置保存在每组 config.json。
README 没有 GIN-PubMed 专用配置，预先固定为 CiteSeer GIN 配方、a_loss=0.1，不根据测试结果调参。
存储惩罚沿用历史代理，不等于真实存储；GAT 代理对两个 q_gat_fea 均使用 hidden×heads 系数，也保留并明确报告这种近似。

每组冻结所选基线的全部参数及状态，只训练每层一个标量门控：GIN 1 个，GCN/GAT 各 2 个。
门控初始为零，Adam 学习率 0.01，无权重衰减，每次更新投影到 [0,1]，训练 100 轮。
整个模型保持 eval，停用 dropout；残差基、编码尺度与量化参数全部固定。侧分支停止梯度，门控及后续主路径仍反传。
以最低验证 CE 选模，门控 epoch 0 纳入候选，平局保留较早轮次；保留最后一轮，零门控回退不作为机制成功。

## 补偿与带权聚合

每个量化聚合块先计算真实残差 R=X-Q(X)，用训练节点处聚合误差的未中心化二阶矩取前两个特征向量作为正交基 B。
GIN/GCN 每层 rank 2；GAT 每头 rank 2，独立编码、传输、解码，然后仍用一个层门控控制所有头。
校准只用训练 mask：基来自训练目标节点的聚合误差，INT8 尺度来自训练源节点的投影值最大绝对值。
完整公共图提供这些节点的邻域，这是传导式设定，不使用验证或测试标签。每层最多 4096 个训练节点，本轮实际训练节点更少。

INT8 侧码在每次前向由当前残差重新计算，不传输完整浮点残差。
GIN 的无权邻居和使用 INT32 累加；GCN/GAT 侧码在带权聚合处解码为浮点，使用原归一化权重/注意力系数进行浮点加权累加。
不宣称 GCN/GAT 是 INT32 累加或端到端整数推理。

GAT 局部参考固定当前输入和同一次前向的注意力系数，只绕过值消息量化。不会用浮点特征重新算注意力来制造目标差异。
绕过值量化时侧码严格为零。此诊断只衡量当前层的值量化误差，不衡量注意力量化误差或完整 FP32 模型差异。
记录补偿前后平方误差、下降比例、余弦、谱、累计能量、侧码饱和率，并验证带门控的正交误差恒等式。
关闭诊断时不运行完整宽度的参考聚合。

## 固定对照与预算

每个所选基线比较四种条件：none（无补偿）、unit（固定全量补偿）、gate（只训练门控）、higher（同额外消息预算提高主消息位宽）。
GCN 和 GIN 每量化层侧码 16 位/节点；GAT 第一层为 8×16=128 位/节点，第二层 16 位/节点。报告按头计算的实际开销，不能把 GAT 总 rank 写成 2。

加位宽对照使用训练校准误差贪心分配整数额外位宽，逐层总和严格等于侧码预算。每通道最多增加 ceil(额外预算/通道数) 位，固定量化动态范围。
较窄输出层允许增加多位，例如 PubMed 三分类输出不可能只靠每通道加一位凑足 16 位。最高位宽不超过 16。
GAT 加位宽对照也用更高精度的值计算注意力，只有一份主消息；补偿组仍用基础值计算注意力。这个对照允许加位宽同时改善注意力，不假装固定同一注意力后还只传一份消息。

固定基、尺度、门控和加位宽配置的活跃状态字节分开报告。通用检查点还保存所有对照所需校准元数据，活跃状态字节不等于检查点文件大小。
门控为零时当前参考实现仍计算侧码，不宣称获得通信节省。
