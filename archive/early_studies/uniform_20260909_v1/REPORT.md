# 零初始化＋标准化条件＋均匀分层 rank

数据集：MNIST；每组 30 轮；种子 [44, 45, 46]；CPU。

## 当前结论

指定组合已经实现并完成新种子对照，但没有复现稳定的准确率提升。MNIST 使用固定 512/256/256 图子集、30 轮、种子 44/45/46；本轮共 21 组训练、630 轮，全部训练完成后才各测试一次。

原 LoRAP 的平均测试准确率为 **39.32% ± 5.69%**；零初始化＋标准化条件＋均匀 rank、采用随机正交基的预先固定主版本为 **35.68% ± 3.85%**，下降 **3.65 个百分点**，三个种子均低于原版。相同组合改用误差谱基为 **39.45% ± 1.03%**，只比原版高 **0.13 个百分点**；逐种子差值为 0、−6.25、+6.64 个百分点，不能解释成稳定收益。无聚合提示基线为 **35.29% ± 2.60%**。

### 组件对照说明了什么

- 取消零初始化后的准确率为 37.50%，取消条件标准化/截断为 36.85%，均值均高于随机基主版本；这些组件的单独收益在本轮没有得到支持。
- 关闭条件投影和门控后为 39.45%，与误差谱基版本均值相同。该控制少 85 个参数（3260 对 3345，少 2.54%），未观察到量化条件优于这个相近容量控制的证据。
- 误差谱基相对随机正交基，三个种子的准确率均提高，平均高 3.78 个百分点，验证 CE 也均更低。这支持将基向量初始化继续作为候选因素研究，但它相对原 LoRAP 的收益尚未稳定。
- 所有新分层版本均固定 [2,2,2,2]；本轮不重新分配 rank。原版为共享提示、2480 个聚合提示参数，新条件分层版本为 3345 个，增加 34.88%。整体比较仍包含容量变化，不能据此单独证明低秩结构优于其他适配器。

### 找到一个具体的标准化问题

三个种子中，主版本第一层的饱和比例条件在 **100% 的验证节点上触及 −5 截断下限**。种子 44/45 的初始化校准饱和比例均值约为 85%/87%，训练后降到约 7%/7%；种子 46 训练后约为 5%。固定初始统计量和 0.1 的尺度下限未能适应这种变化，导致第一层该条件的节点差异被截断抹掉。其他条件及后续层未出现同样的大面积截断。

这是实际观察到的条件分布变化，不能单独断言它造成了准确率下降。本轮保留预先声明的方法，没有根据测试结果回改配置。下一次受控改动可优先针对有界饱和比例设置覆盖 [0,1] 的尺度，或使用仅在训练阶段更新的统计量；这些替代方案尚未在本轮训练验证。

### 量化补偿的证据仍不足

随机基主版本的 12 个“种子×层”完整 GIN 局部误差指标中，只有 5 个降低；降低率范围为 −0.0694% 至 +0.1600%，提示与目标修正的余弦范围为 −0.0756 至 +0.0637。谱基版本只有 4/12 个降低，范围为 −0.4061% 至 +0.0287%。没有形成跨层一致的局部误差降低。

这些指标固定各自当前层输入，只绕过该层消息量化，并包含 GIN 自身节点项。不同方法上游输入不同，它们不是对同一个完整 FP32 教师的误差。上述结果既不能证明提示主要学到了量化补偿，也不能据此证明它只学到了容量。

训练前误差的原始 rank-2 能量为 94.95%–99.04%，去均值后为 71.72%–90.84%。低秩结构有压缩空间，但原始谱中的均值方向影响较大；高谱能量并不保证分类收益。

主版本最佳检查点在验证集上的**邻居量化误差**，rank 2 仅覆盖 23.20%–54.74% 的能量。它与训练前校准的**完整 GIN 更新误差**在数据和误差定义上都有区别，不能直接把差异归因于训练过程；但初始化谱的高覆盖率显然不能直接证明训练后 rank 2 足够。

### 验收与限制

38 项单元测试通过；21 组初始化、最低验证 CE 检查点和验证指标均已重现，审计没有重复测试。保存了全部逐轮日志、检查点、数据索引、校准、条件分布检查、量化误差、实际位宽、参数开销和源代码快照。

所有组的验证预算代理仍高于既定目标 0.1，不能称为已经达到存储预算。平均有效激活位宽、预算代理和 FP32 提示开销分别报告，不把相同预算目标当成相同物理存储。

新种子沿用此前的数据划分，因此仍是小样本开发验证；不能把这里的准确率当成完整 MNIST 基准，也没有独立新测试集或论文级收益结论。CiteSeer 的同一接口与完整配置已保留，本轮新增训练集中在具有四个提示位置的 MNIST。两数据集全划分、200 轮、种子 41–50 的配置和命令已生成，未执行。


## 固定方法与实验边界

主版本 `main` 在训练前固定，不按本轮验证或测试结果挑选变体。配置顶层 basis 字段描述主版本，具体对照按 variant 决定其实际初始化（例如 spectral_basis 使用误差谱基）。各提示层独立使用 rank 2 的低秩因子，共享打分层、条件投影和门控。左因子为零、右因子为随机正交行向量；零的是初始修正输出，并非两个因子同时置零。首次更新可学习左因子，后续其他提示参数获得梯度。

令 S 为量化消息的邻居和，ρ=√max(mean(S²),10⁻¹²)，z=clip((c−μ)/s,−5,5)。每层使用：

```text
A_l = 0,  B_l B_lᵀ = I₂  （仅初始化时）
p_l = max(stopgrad(ρ), ρ_floor,l) · 2σ(g(z_l))
      · softmax(a(S_l / ρ_l) + C z_l) · A_l B_l
output_l = S_l + p_l
```

条件投影与门控参数也初始化为零，因此初始门控倍率为 1。RMS 查询归一化和幅度缩放沿用上一轮稳定化结构；本轮只改变表中指定组件，没有单独消融 RMS 操作。正交性仅是初始化，不作为训练约束。

条件依次为 log1p 入度、消息量化器平均对数步长、平均有效位宽/8、邻居饱和比例，均由实际消息边和量化器计算并停止梯度。无邻居时饱和比例为零。训练校准 μ 为均值，s 为总体标准差与 [0.5,1,0.125,0.1] 的逐项最大值，避免常量条件除零。当前消息位宽冻结，位宽条件基本为常量；本实验不验证跨位宽泛化。

MNIST 校准只使用训练子集的前 128 张图，每层最多固定抽样 4096 节点；CiteSeer 仅统计训练 mask。主版本校准只需量化聚合和条件统计，不运行未量化参考或 SVD。本次若包含 spectral_basis 对照，共用离线误差谱校准结果中的相同统计量；只有该对照把参考误差基向量写入可训练因子。

| 变体 | 相对主版本的变化 |
|---|---|
| `none` | 移除聚合提示；MNIST 输入 GPF-plus 保留 |
| `original` | 原共享 LoRAP；整体结构与容量均不同 |
| `main` | 零左因子＋标准化/截断条件＋随机正交右因子＋每层 rank 2 |
| `nonzero_start` | 只将左因子改为 Xavier 随机初始化 |
| `raw_conditions` | 只取消条件标准化及截断 |
| `no_conditions` | 移除条件投影与门控，少 85 个有效参数 |
| `spectral_basis` | 只将右因子初始化改为训练局部误差谱基 |

同种子共享骨干、输入提示、打分层初始权重与数据顺序；各控制间应相同的右因子也一致。所有提示参数使用主学习率与零权重衰减，量化器学习率、存储惩罚和调度沿用既定配置。每组以最低验证交叉熵选模，平局取早；所有组训练结束后，各最佳模型只评估一次测试集。

新种子用于检查初始化敏感性；验证/测试划分仍与前轮相同，不能称为独立新测试集。若使用 MNIST 512/256/256 子集，这仍是小样本开发实验，不代表完整 MNIST 基准。
