# LoRAP 实验总结（截至 2026-10-20）

本归档记录标准权重 LoRA、GLoRA、GraphLoRA-adapted 的实现及实验，以及 Table I 中 GPF-LoRAP 的固定配置重跑和四轮调参。最终表格按每个目标配置**最新完成、由验证集选定的轮次**更新，不从历次测试成绩中取最大值。历史结果和失败于对照的早期结果均保留。

## 当前结论

- Table I 的 GraphLoRA-adapted 已完成 **45 个配置 × 3 个种子 = 135 次训练和测试**。
- 针对原表中落后于 GraphLoRA 的 10 个配置，完成 30 次固定配置重跑，再对仍落后的配置逐轮调参。最终这 10 个配置的 GPF-LoRAP 测试均值在指标方向上均高于固定 GraphLoRA 对照，但不等于统计显著领先，也不代表全表 45 个配置均领先。
- **ZINC–GCN–DQ 基本持平**：GPF-LoRAP MAE 为 **0.5670 ± 0.0090**，GraphLoRA 为 **0.5676 ± 0.0097**；仅相差约 0.0006，仍高于原表 GPF-plus 的 **0.534 ± 0.017**（MAE 越低越好）。因此不能声称这一项已经取得明确优势。
- QAT–CIFAR10–GCN 经扩大训练参数搜索后达到 **47.21 ± 2.24%**，固定 GraphLoRA 为 **43.62 ± 0.92%**；最终新配置训练 **300 轮**，GraphLoRA 为 **200 轮**。这是增加训练和搜索预算后的探索结果。
- GLoRA 按用户要求停止，**没有完成正式测试**；不提供或推断其完整测试成绩。

初筛与晋级可能是同一个训练实例的续训，复用模型也不产生新训练；这些列不能简单相加解释为独立完整训练数。上述 Table I 扩展累计产生 **204 个新的最终测试记录**；最终表格实际引用 135 个 GraphLoRA 和 30 个最新 GPF-LoRAP 测试记录。

每个配置按最低验证任务损失选择检查点，平局取较早轮次。第一轮由种子 41 验证集选择配置，随后确认另外两个种子；第二至四轮在种子 41 初筛后，以决赛配置三个种子的平均最佳验证损失选定配置。配置锁定后，每个最终模型测试一次；复用模型沿用既有测试缓存。调参阶段没有按测试值在候选之间选优。

需要同时说明：**继续调哪些配置、是否开展下一轮，是在查看此前测试结果后决定的**。因此整体过程仍是面向同一测试集的反复开发，并非一次性预注册的独立最终评估。GraphLoRA 也没有获得同等搜索预算。本文保留全部轮次和这些限制，不能据此声称方法已经普遍优于 GraphLoRA。

Cora/CiteSeer 使用完整公共划分，MNIST/CIFAR10 使用官方完整图划分，ZINC 使用官方 subset 划分（10,000/1,000/1,000）。通常 200 轮，节点 GAT 250 轮，最终 QAT–CIFAR10–GCN 为 300 轮。每项精确配置、初始化指纹、实际量化位宽、耗时、显存和参数量见对应实验目录。

## 实现及验证

- 标准 LoRA：量化线性主分支和 FP32 低秩分支共享一次输入量化，零输出初始化，无自动合并；联合训练骨干和既有可训练量化参数。
- GLoRA：保留实现、数值/流程测试和停止时记录；20 个预定模型中完成 6 个超网络及结构搜索，正式测试为 0。
- GraphLoRA-adapted：移植低秩图分支和辅助目标到量化 GIN/GCN/GAT；同域联合训练，无源图预训练/跨域 SMMD。ZINC 的回归目标另作适配。**不是原论文跨图迁移实验复现。**
- 单元测试覆盖零初始化等价、显式低秩公式、梯度、优化器分组、量化调用次数、空边/孤立节点、多图独立性、保存恢复、测试释放、调参选择及 AdamW 恢复。
- 原始 GPU 数值回归、真实数据 smoke、完成审计记录随实验归档。发布审计校验原文件 SHA256、165 个最终测试记录及其最佳检查点，不重新执行测试集推理。
- 完整表格已通过数值、结构和来源校验；原环境没有 TeX 编译器，未声称已经编译通过。

## 归档范围与复现边界

仓库包含当前研究代码、第三方来源记录、主要实验的原始报告/配置/划分/初始化/逐轮日志/测试指标/源码快照，以及主要实验的 `best.pt`。Table I 冻结实验仅完整收录所需的 135 个配对无提示对照，其余早期探索提供摘要。所有筛选轮次保留候选验证记录，包括落后结果。

数据集、运行锁、逐 batch 预测缓存、优化器和 RNG 的 `last.pt` 不上传；它们保留在原实验机器。上传的最佳模型可供检查，发布包不承诺从任意中途训练状态精确续训。`archive_manifest.json` 列出收录文件的 SHA256 及范围内省略文件的原因。原始文件中的绝对路径保留为历史证据，不改写哈希；新机器运行需按根目录 README 配置数据路径。

原始工作区来源为 A-2Q；内含第三方 DQ、GraphLoRA、GLoRA 源码及原有许可证/来源文件。仓库未擅自给全部上游代码重新授予统一许可证。
